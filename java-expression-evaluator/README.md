Java Arithmetic Expression Evaluator

Project Overview

This project is a Java console application developed for COSC 2336 – Data Structures at Lamar University.

The application evaluates mathematical expressions entered by the user using two stack data structures: an operand stack and an operator stack.

Features

Accepts mathematical expressions as user input.

Supports addition, subtraction, multiplication, division, modulus, and exponentiation.

Uses stacks to process mathematical operators.

Supports parentheses and operator precedence.

Displays the calculated result.

Provides basic error handling for invalid expressions.

Technologies Used

Java

Java Collections Framework

Eclipse IDE

How to Run

Open the project in Eclipse.

Ensure the Java file is in the EvaluateExpressionAydenManuel package.

Run EvaluateExpressionAydenManuel.java.

Enter a mathematical expression when prompted.

Example

Input:
(5 + 3) * 2

Output:
(5 + 3) * 2 = 16
